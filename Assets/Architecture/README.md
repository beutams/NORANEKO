# AI 架构编辑器

点击 Unity 顶部工具栏的 **Documentation** 按钮打开。画布由 IMGUI 自绘，不依赖 GraphView。

AI 如何依据 Node、接口、父子关系和预制模块实现功能，见 [AI 架构工作规范](AI_WORKFLOW.md)。

## 界面

- **左侧**：顶部搜索框；“类型”显示普通模块和预制模块，可拖入画布；“目录”显示画布中的全部节点，包括尚未连接的节点。
- **中间**：节点自上而下排列。从左侧拖入画布时立即创建并保存节点，可直接选中和编辑。有子节点的卡片右上角可点击 `-` 收起整棵子树，再点击 `+` 展开；收起只影响画布显示，节点及接口数据保留，目录中仍能找到它们。将父节点下方的蓝色端口连到另一个节点上方的蓝色端口，只会设置该节点的归属关系。每个节点下方列出接口标题；从接口行拖到使用该接口的模块，可记录引用。单击或框选是弱选中；双击接口是强选中，一次只显示该实例的这一个接口到使用模块的直线引用，连线从接口中心到目标模块中心。再次单击或框选会返回弱选中。空白处拖拽可框选，松开鼠标后选框消失、节点保持选中；Shift/Ctrl 点击可增减选中节点。拖动选中的卡片可一起移动节点及其子树。中键平移，滚轮缩放。
- **右侧**：顶部文本框直接修改节点或预制模块名称。每个节点有独立的“功能”文本；预制实例还显示其预制定义的“预制文本”，两者分别保存。下面是“接口”列表，每个接口有标题和内容，没有参数。选中接口所属的节点时，还可查看和移除该实例的引用记录。

画布框选节点后按 Del 可一次删除所选节点及其子树，Root 不会被删除；选中预制模块的固定子节点时会删除完整预制实例。画布获得焦点后，Ctrl+C 复制选中的节点及其子树，Ctrl+V 在原归属下错位粘贴；选中预制模块的固定子节点时会复制完整预制实例。Ctrl+Z 撤销，Ctrl+Shift+Z 或 Ctrl+Y 重做。Ctrl+S 可立即保存。顶部的“自动排版”和“适应画布”只在点击对应按钮时执行，并按当前展开的节点计算；新增、连线和修改预制结构会保留当前排布与视图。折叠状态按项目保存在编辑器偏好设置中，不写入架构数据。更改会自动保存，顶部显示“未保存/已保存”状态。

## 预制模块

预制模块的“预制文本”和“接口”列表由其实例共享，每个画布节点的“功能”文本独立保存。选中左侧预制定义或画布中的实例都可编辑预制文本。预制定义标题旁的“...”菜单可添加固定子节点。所有模块都可以附加子模块；固定子节点由预制定义同步到现有实例，不能单独改挂。选中左侧预制定义后按 Del 可删除定义及其实例。

## 数据文件

[`architecture.json`](architecture.json) 分别保存节点的 `functionText` 和预制定义的 `presetText`，还保存节点归属、接口标题与内容以及接口引用。尚未连接的节点也会保存；打开旧版文件时，旧预制功能文本会迁移到 `presetText`，旧接口说明会转换为列表项并生成标题。
